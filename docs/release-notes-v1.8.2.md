# Eagle MultiView 1.8.2

这一版起，Mac 和 Android App 都能在 App 内检查并安装更新；另外改进了触屏操作，修复了平板长按卡死等问题。

## 新增：检查更新

**Mac**

- 菜单“Eagle MultiView → 检查更新…”随时检查；App 每天也会自动检查一次，更新窗口里可关闭自动检查。
- 发现新版本时显示更新说明，可选“跳过此版本”“稍后提醒”或“下载并安装”。
- 安装包在 App 内下载（显示进度，可取消），先用 Release 中的 `SHA256SUMS.txt` 校验，再核对 App 标识、版本和签名，然后点“立即重启并更新”即可替换“应用程序”中的 Eagle MultiView 并重新打开；选“稍后”会在下次退出时安装。有未保存的 TXT 时会先照常提示，取消退出则不会替换。

**Android**

- 连接页底部显示当前版本和“检查更新”；App 每天也会自动检查一次。
- 安装包下载并校验后交给系统安装程序。第一次需要在系统设置中允许 Eagle MultiView 安装应用，返回后自动继续安装。

> 1.8.1 及更早版本没有这项功能，需要手动安装这一版；之后的版本就可以在 App 内更新。

## Android App 与触屏

- 触屏选择与点击一致：轻点选中（替换选择），再点已选中的素材打开预览，再点已选中的文件夹卡片进入；长按加选，没有选择或长按已选项时打开菜单；点空白处清除选择。
- 修复：在卡片上第二次长按后整个页面卡死（Android WebView 发起了一个不会结束的触摸拖放）。
- 宽屏平板上按返回也会先清除选择，而不是直接退出。
- 短暂断网不再遮住页面或在恢复后重新加载，文件夹、预览和草稿都保留，网页自行重连。
- 可选“记住访问地址”（默认关闭）：自动保存连接过的地址，可固定并命名；在已保存的地址之间切换保留各自的登录；当前地址无法连接时自动尝试其他已保存的地址。
- 触屏上的预览只保留 ‹ ›，下滑、返回或 Esc 关闭，评分在详情面板；手写笔也能滑动切图和关闭预览。
- App 图标改为桌面版图标；深色模式下连接页文字清晰；外接键盘回车只连接一次，连接后收起软键盘；视频可全屏；隐藏 App 中无效的“新建窗口”。

## 桌面与网页

- “打开文件所在的位置”可在当前视图前 3,000 个素材中直接找到并选中目标，不再翻几页后静默放弃；更深或不存在时给出提示。
- 勾选“包含子文件夹”应用的排序会稳定作用于所有子文件夹（包括之后新建的），大资料库中不再被挤掉；把这样的文件夹设回 Eagle 顺序时，子文件夹也一起恢复。
- 侧边栏、卡片和详情面板的字号、行高和颜色对齐 Eagle 4.0。

完整列表见 [CHANGELOG](https://github.com/khkjdfkjhdsfakhds/eagle-multiview/blob/v1.8.2/CHANGELOG.md)。

## 下载与升级

- macOS Apple silicon：`Eagle-MultiView-1.8.2-arm64.dmg`。临时本机签名，未经 Apple 公证；首次打开请在 Finder 中右键选择“打开”。
- Android：`Eagle-MultiView-1.8.2-android.apk`（debug 签名，与 1.8.1 相同，可直接覆盖安装并保留数据）。
- 校验文件：`SHA256SUMS.txt`。
- 编辑 TXT 仍需在 Eagle 中启用 App 随附的后台保存插件，见[启用说明](https://github.com/khkjdfkjhdsfakhds/eagle-multiview/blob/v1.8.2/eagle-plugin/text-save-service/README.md)。
- 内置 Web 服务为 HTTP，仅用于可信局域网，不要直接映射到公网。
- 不提供 Windows 桌面版。
