# Eagle MultiView 1.8.0

在 Mac 上多窗口、多分栏整理 Eagle 素材，通过浏览器在手机、平板和另一台电脑继续使用同一资料库。

这是自 GitHub 1.6.0 以来的累计更新，包含本地 1.7.0 和后续审查修复。网页与手机访问在 1.6.0 已加入，本版继续完善移动布局、复制、传输、连接恢复及跨视图状态。

## 主要更新

### 更完整的多分栏工作区

- 统一 12 种布局图标，新增一次刷新所有分栏。
- 素材、文件夹和当前路径可通过右键在另一窗格定位或打开。
- 改善路径导航、排序继承、方向记忆、滚动恢复及窄窗口布局。
- `Shift-S` 切换全屏预览同步，并显示缓慢淡出的反馈；普通网格操作保持各栏独立。
- `Command-+/-` 只调整中间素材网格大小，与滑块同步；`Command-0` 恢复默认。

### 整理与导入

- 移动文件夹本身，并检查目标关系和切库状态。
- 拖动手动排列文件夹和素材，顺序保存在 MultiView 本地。
- 刷新缩略图，从文件或剪贴板设置缩略图，按项反馈成功、失败或不确定结果。
- 输入 ArtStation 作者主页，分批发现作品、选择图片、处理重复后导入到固定目标。
- 修复导入、导出、重复项、回收站、批量操作和切库期间的状态边界。

### TXT 后台保存与草稿保护

- 随 App 附带 Eagle 官方 Plugin API 后台服务，通过 `Item.replaceFile()` 保存 TXT，取消直接写库回退。
- 保存前检查内容版本，保留草稿与备份，处理断连、冲突和结果不确定情形。
- 输入时减少状态闪动，仅显示“编辑中 / 已保存”；失败原因可通过详细提示查看。
- 需要在 Eagle 中加载并启用新版配套插件，见[启用说明](../eagle-plugin/text-save-service/README.md)。

### AI 元数据

- 读取 WebP RIFF/EXIF 内嵌生成信息。
- NovelAI 角色正面提示词按角色单独展示和复制，放在全局正面与全局负面之间。
- 保留常见 NovelAI、WebUI、ComfyUI 和 InvokeAI 元数据读取；缺失元数据的图片不能还原生成参数。

## 网页与手机访问

在 Mac 的 MultiView 菜单选择 **显示 → Web 访问…**，开启后让手机/平板连接同一局域网，扫描地址二维码或输入界面给出的地址，再输入访问密钥。Eagle、MultiView 和 Mac 必须保持运行。

支持文件夹与筛选、素材预览、长按菜单、触控缩略图缩放、下拉刷新、选择栏、上传与下载，以及主机变更同步。浏览器端不提供 Finder 定位、原生文件拖出和 Mac 默认应用打开。

内置服务为 HTTP，按可信局域网用途使用；不要直接暴露公网。添加到主屏幕和独立 PWA 安装能力取决于浏览器与协议。Android 客户端外壳源码保留，本次不发布 APK。

## 下载与升级

- macOS Apple silicon：`Eagle-MultiView-1.8.0-arm64.dmg`
- 校验文件：`SHA256SUMS.txt`
- **停止提供和维护 Windows 桌面版**。旧版 Windows 安装包仅作历史存档；Windows 浏览器可连接 Mac 主机。

先退出旧 MultiView，将新 App 拖入“应用程序”，再打开。需要 Eagle 4.0 Build 21 或更新版本，以及 macOS 13 或更新版本。macOS 包使用本机临时签名，未经过 Apple 公证；首次打开受阻时在 Finder 右键选择“打开”，无需关闭系统安全机制。

## 使用边界

- Eagle 是资料库事实来源；元数据修改经 HTTP API，TXT 正文经官方后台插件。MultiView 本地顺序、置顶和标签颜色不会改写 Eagle 本体的相应状态。
- 不提供永久删除、资料库修复或合并。
- 当前 SDK 不接受零字节 TXT；清空后的正文保留为草稿，不填入空格伪装保存成功。
- 缩略图“刷新”不等于“取消自定义”；后者尚无受支持接口。
- Web 下载每次最多 500 项、合计 3.5 GB；浏览器显示开始下载不等于传输已经完成。

## 验证范围

- 自动测试：630 项通过；最终安装包内界面集成测试 4 项通过。
- 构建：Apple silicon arm64，严格本机签名检查通过；DMG 内应用与安装版内容一致，未公证。
- 公开演示库实测：多层文件夹、独立窗口与双栏浏览、素材详情、预览开关、Web 密钥登录及手机尺寸页面。
- 手机截图使用浏览器尺寸模拟；本轮未覆盖全部手机真机、Finder 跨应用拖放或完整写入回归，不据此承诺所有系统路径均已验收。
