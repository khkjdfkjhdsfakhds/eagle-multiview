## 与原版不同 / 没做（已知、已告知用户）

- P3-05：MultiView 的提示比原版多，可能更早顶掉撤销；智能文件夹、标注的撤销依赖 Eagle 4.0 内部结构，形状不符时不做任何改动。
- P4-01：`.key`、`.pxd`、`.mindnode` 这类“包”目录按普通文件夹处理（原版当文件）。
- 文件夹多选：排序方式、快速访问、导出、文件夹图标、智能文件夹多选没做；多选删除后各栏回到“全部”（原版跳到兄弟文件夹）。
- 菜单栏：不按选择状态灰显（原版也不灰显）；菜单“复制”与 ⌘C 一致（比原版多复制文件）；原版有但 MultiView 没有对应功能或 API 不支持的项没放（列表见归档第三十六节）。
- 标签群组顺序只在 MultiView 本地（API 没有群组排序接口）。
- 用户决定不做：每栏条件 chip 条、浅色主题、智能文件夹条件编辑器、以图找图；Web 安全只在“Web 访问”窗口说明明文 HTTP 风险（不做每设备令牌/HTTPS）。

## 规则摘要（详见 `.claude/CLAUDE.md`）

- 看齐 Eagle 原版，不是“在原版基础上改善”：改行为前先读 Eagle 代码（解包 `Eagle.app/Contents/Resources/app.asar` 读 `app/app.bundle.js`、`i18n/zh_CN.js` 等）或实际观察原版。
- 已定、不要再改：`/` 在“全部展开并定位”与“全部收起”之间切换；切换视图清空搜索与筛选（“锁定筛选”除外）；菜单栏保留 MultiView 现有快捷键，只补原版有、未占用且带 ⌘ 的键。
- 未合并分支用测试版（appId `local.eagle.multiview.branchtest`、Review 版本号）验证，不覆盖正式安装。
- 一次做一项：一项做完、测试、提交，就更新本文件；上下文变长时换新会话。
