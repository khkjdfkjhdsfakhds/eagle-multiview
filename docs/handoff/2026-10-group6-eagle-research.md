# 第 6 组原版对标调研（2026-10-15）

依据：解包 Eagle 4.0.0 的 `app.asar`，读渲染端源码（`app/index.html`、`app/js/directives/*.html`、`app/js/default-preferences.js`、`app/js/lib/api/filter.js`、`app/app.bundle.js`、`app/js/api-v2-playground-config.js`、`i18n/zh_CN.js`）。主进程是字节码读不了，菜单结构从 i18n 键和默认快捷键表推断。本文只写结论和建议，不改代码；每节末尾的“建议”供用户挑选范围。

## 先说结论

| 项 | 原版要点 | MultiView 差距 | 建议档位 | 工作量 |
|---|---|---|---|---|
| A 菜单栏（GUI-01/P3-01/P3-02） | 10 个顶层菜单、约 90 个默认快捷键 | 只有 5 个菜单，9 个已写好的命令没接；多处快捷键与原版冲突 | 推荐：按原版重建，API 不支持的项不放 | 中（主要在 `main.js`） |
| B 检查器（P2-01～03） | 名称→注释→链接→**可拖动排序的区块**（标签/文件夹/标注/基本信息）；多选也用同一套 | 缺“文件夹”区块；评分是下拉；日期字段不全；多选是另一套面板 | 推荐：补文件夹区块、星级评分、三种日期、多选并入同一结构 | 中 |
| C 筛选条（GUI-11/12、P7-07） | 筛选按钮开关一条工具条，19 种条件 chip，可增删排序；切换文件夹自动清空，可“锁定” | 大表单弹层；缺文件夹/时长/修改日期/标注等条件（切换清空与锁定已于 10-14 对齐） | 分两步：先补缺失条件，再换成 chip 条 | 大 |
| D 文件夹颜色与描述（P1-12/P2-05） | 右键 8 色+无；检查器名称、描述、文件数、占用空间、添加日期 | 没有设置颜色和描述的入口 | 推荐：全做（API 支持） | 小～中 |
| E 子文件夹内容与卡片信息（P1-06/P1-07） | 两者都是**全局**开关，不分文件夹 | 都没有 | 推荐：全做，全局存储 | 中 |
| F 标签管理（GUI-08） | 左栏 全部/未分类/常用标签/群组；右侧首字母分段 chip；搜索；排序 | 一长串行列表 | 推荐：重做布局，常用标签只读 | 大 |

顺带定下的几项（可直接修，属 P2）：

1. **R2-04**：原版切换视图时，若筛选没有“锁定”，会清空筛选条件**和搜索词**（`resetPage` 里 `if (!eagle.filter.isLock) { resetFilter(); keyword = undefined; }`）。点“清除”会同时解除锁定。**更正**：MultiView 已在 2026-10-14 按此实现（`b08d2a1`），本文初稿误写为未做。
2. **P1-04 日期语义**：原版检查器“添加日期”= `modificationTime`，“创建日期”= `btime`（缺省时退回 `modificationTime`），“修改日期”= `mtime`（同上）；排序和智能文件夹规则也是如此。MultiView 之前把 `btime` 当添加日期，已于 2026-10-15 修正（`c39bc89`）。
3. **P1-09 更正**：原版布局按**资源库**记忆（`eagle.list.layout.<库路径>`，无则用全局），卡片显示开关全局，排序按文件夹（文件夹 `orderBy` 为空时“使用全局设置”）。审查文档里“视图设置可按文件夹单独设置”只对排序成立。
4. **AI 搜索**：API 有 `/api/v2/aiSearch/searchByText`、`searchByItemId`、`searchByBase64`（需用户装了 Eagle 的 AI 搜索服务，`isReady` 可查）。“以图找图（本机）”和“语义筛选”不再是“API 不支持”，可作为可选项。

## A. 菜单栏

### 原版

顶层：应用、资源库、文件、编辑、查找、整理、显示、窗口、插件、帮助。主要内容与默认快捷键（`default-preferences.js`）：

- **文件**：新建…（⌘N）、新增文件夹（⌘⇧N）、新增子文件夹（⌥N）、新增智能文件夹（⌘⇧⌥N）、导入本地文件夹/链接/素材包/ArtStation（⌘⇧⌥S）、导出到计算机（⌘E）、导出指定格式（⇧E）、导出 CSV、扫描重复文件。
- **编辑**：撤销/重做、剪切/复制/粘贴、全选、重命名（⌘R）、复制文件路径（⌘⌥C）、复制文件夹路径（⌘⌥⇧C）、复制 Eagle 链接/缩略图/Base64/名称、创建副本（⌘D）、刷新缩略图（⌘⌥R）、自定义缩略图（⌘⌥T 文件 / ⌘⇧⌥T 剪贴板）/取消、编辑图像（裁切 ⇧C、旋转 ⇧R、翻转 ⇧F、拼图 ⌘⇧M）、编辑文件夹（设置当前文件夹 ⌘⇧R、密码、移动）、文件夹排列、从文件夹中移除（⌘⇧⌫）、丢到回收站（⌘⌫）、切换资源库（⌘L）。
- **查找**：搜索（⌘F）、在“全部”搜索（⌘⌥F）、快速切换文件夹（⌘J）、筛选侧栏项目（⌥⇧F）、打开筛选器（⌘⇧F）、重置筛选器（⌘⇧⌥F）、各筛选器（文件夹 ⌥F、标签 ⌥T、颜色 ⌥C、形状 ⌥S、评分 ⌥R、日期 ⌥D、格式 ⌥E，其余无默认键）、以图找图、添加至文件夹（⌘⇧J）。
- **整理**：添加标签（⌘T）、复制标签（⌘⇧C）、粘贴标签（⌘⇧V）、清除标签、添加至上次使用的文件夹（⇧D）、评分 0～5（无默认键）。
- **显示**：全部/未分类/未标签/最近/随机/标签管理/回收站（⌘1～⌘7）；布局 网格/自适应/瀑布流/列表（⌥1～⌥4）；放大/缩小/原始大小/适合宽度（⌘= ⌘- ⌘0 ⌘9）；在浏览器打开链接（⌘⇧O）、默认应用打开（⇧Enter）、在访达中显示（⌘Enter / ⌘⌥S）、新窗口打开（⌘O）；滚动 Home/End/PageUp/PageDown；左栏/右栏/两者（⌘⌥1/2/3）；显示名称/尺寸/标注（⌘⌥4/5/6）、显示子文件夹内容（⌘⌥7）、导航器（⌘⌥8）；黑白预览（⌘⌥G）；窗口置顶（⇧T）；幻灯片（F5）；播放器控制。
- **应用**：偏好设置（⌘,）、立即锁定（⌘⌥L）、检查更新等。

### MultiView 现状

菜单只有 应用/文件/编辑/显示/窗口；“窗口”项是英文；“复制”“全选”走原生 role（P3-02）；`preload.js` 里 9 个命令（丢到回收站、置顶、添加/移动/移除文件夹、添加标签、评分、标签颜色、新窗口）renderer 已就绪但菜单没发。大量功能只有快捷键或右键入口。

**快捷键冲突**（同一个键，两边含义不同）：

| 键 | 原版 | MultiView |
|---|---|---|
| ⌘1～⌘4 | 切换到 全部/未分类/未标签/最近 | 分栏布局 |
| ⌘⇧N / ⌥N | 新文件夹 / 新子文件夹 | ⌥N 新文件夹（在文件夹内为子文件夹），⌘⇧N 无 |
| ⌘⇧O | 在浏览器打开链接 | 导入文件 |
| ⌘⇧R | 设置当前文件夹（自动标签） | 重新载入窗口 |
| ⌘⇧L / ⌘⇧I | 锁定文件夹 / 无 | 切换侧栏 / 检查器（原版是 ⌘⌥1 / ⌘⌥2） |
| ⌘⌥N | 无 | 新窗口 |

MultiView 没有、原版有默认键的：⌘T 添加标签、⌘J 快速切换文件夹、⌘⌥F 在全部搜索、⌘⇧F 打开筛选器、⌥1～⌥4 布局、⌘⌥R 刷新缩略图、⌘⌥T 自定义缩略图、⌘⌥S 在访达中显示、⇧T 窗口置顶、⌘⌥G 黑白预览、⌘9 适合宽度、⌘⌥4～7 显示开关。

### 建议

- **最小**：修 P3-02（复制/全选改自定义 click）；窗口菜单中文；接上 9 个已就绪命令；补“帮助”菜单（错误日志、检查更新）。
- **推荐**（我的建议）：按原版 10 个顶层菜单重建（“插件”不做），只放 MultiView 真能执行的项；按选择状态启用/禁用（renderer 上报精简状态）；对话框打开时菜单命令不执行（F-05）。快捷键冲突按“原版优先、MultiView 特有功能另找键”处理：⌘1～7 改为原版视图切换，分栏布局改用 ⌃⌘1～4 或只放菜单；⌘⇧N/⌥N 按原版；⌘⇧O 改为打开链接、导入改 ⌘⇧I；侧栏/检查器改 ⌘⌥1/⌘⌥2；重新载入窗口去掉快捷键或移到“帮助 › 开发”。
- **不做/灰显**：编辑图像、密码保护、素材包、扫描重复、导出 CSV、插件、偏好设置（MultiView 没有对应设置页）。

**需要用户决定**：快捷键冲突是否按原版改（会改变现有使用习惯，尤其 ⌘1～4 分栏和 ⌥N）。

## B. 检查器

### 原版

单选时从上到下：缩略图 → 主色（右键直接按该色筛选）→ 名称 → 注释（多行，可识别链接）→ 链接（输入框 + “在浏览器打开”按钮，可把网址拖进来）→ **可拖动排序的区块**：标签、文件夹、标注、基本信息（顺序用户可调，每块可折叠）。

- **文件夹**区块：所属文件夹 chip（带文件夹颜色，悬停显示完整路径，右键可看路径）、chip 上的 × 从该文件夹移除、“+ 添加文件夹”（快捷键 F）。
- **标签**区块：chip（带标签颜色）、×、“+ 添加标签”（快捷键 T）；右键 复制/粘贴/清除全部标签。
- **标注**：只在有标注时出现，可拖动排序。
- **基本信息**：评分（5 颗星，点击设置）、尺寸、时长、BPM、文件大小、格式（可点击改扩展名）、相机参数（RAW）、添加日期、创建日期、修改日期；底部“导出”按钮。

多选：同一个面板。顶部最多 5 张缩略图堆叠，“已选 N 个文件”（≥100 显示警告色），名称隐藏，注释和链接可批量编辑（不同时显示“多个链接”），标签和文件夹显示共同项，基本信息只有评分和合计大小。

### MultiView 现状

顺序是 名称 → 标签 → 评分（下拉）→ 备注 → 来源 → 评论 → 文件信息（格式、大小、尺寸、修改日期）→ 生成元数据（MultiView 增强）→ 操作按钮。没有文件夹区块，日期只有一个；多选是另一套面板（共同标签、批量评分、批量加标签、删除）。

### 建议

- **推荐**：
  1. 加“文件夹”区块（chip 点击在当前栏导航、× 移除、“+”复用 ⌘⇧J 的选择器），单选多选都有；
  2. 评分改 5 颗星放进“基本信息”；
  3. 顺序改为 名称 → 注释 → 链接 → 标签 → 文件夹 → 评论/标注 → 基本信息 → 生成元数据；
  4. 基本信息补 时长、添加/创建/修改三种日期（语义见开头第 2 条），非图片不显示尺寸；
  5. 多选改用同一结构：缩略图堆叠 + “已选 N 个”+ 批量注释/链接 + 共同标签 + 共同文件夹 + 评分 + 合计大小；
  6. 检查器内 T / F 单键打开标签/文件夹选择（焦点不在输入框时）。
- **可选**：区块拖动排序与折叠（存本地）；点击格式改扩展名（API 不支持改文件，不做）；导出按钮（不做）。

## C. 筛选条

### 原版

- 工具栏的筛选按钮（⌘⇧F）开关一条横向工具条，开关状态存 localStorage，跨视图保持打开。
- 工具条上是条件 chip，默认显示 颜色、标签、文件夹、形状、评分、格式；其余（以图找图、语义、添加日期、修改日期、分辨率、时长、大小、标注、备注、网址、字体、BPM、相机）通过“+”加入；chip 可拖动排序，顺序和显示集合存 localStorage。
- 每个 chip 点开是小弹层：标签有 任意(OR)/全部(AND)/完全相同、“未标签”；形状有 横/竖/方/全景横/全景竖/4:3/3:4/16:9/9:16；日期有 今天/昨天/7/30/90/365 天和按年月；评分、格式、形状带计数。
- 右侧：“保存的筛选器”、**锁定**、清除（⌘⇧⌥F）。切换视图时未锁定就清空筛选和搜索词。

### MultiView 现状

“筛选”按钮打开一个大表单（搜索范围、格式文本框、评分、形状、颜色、大小 MB、百万像素、添加日期、备注、来源、标签文本框），关闭后只有按钮上的数字。缺 文件夹、修改日期、时长、标注、按宽高的分辨率；格式和标签不是勾选列表；没有锁定，切视图不清空。

### 建议

分两步，第一步收益大、改动小：

- **第一步（推荐先做）**：补 文件夹（包含/排除）、修改日期、时长、标注 条件；格式改为带计数的勾选列表；标签支持 任意/全部/完全相同 和“未标签”；日期加原版的快捷区间。全部走现有客户端过滤管线。
- **第二步**：把表单换成每栏标题下的 chip 条（窄栏收成“筛选 (N)”），chip 弹层复用第一步的控件；“+”加减条件、顺序本地记忆。
- **可选**：保存的筛选器（MultiView 已有“另存为智能文件夹”，可先不做）；以图找图/语义（需 Eagle AI 服务，见开头第 4 条）。

## D. 文件夹颜色与描述

### 原版

- 文件夹右键：新增子文件夹（⌥N）、移动文件夹、添加至/移出快速访问、重命名、复制链接、设置自动标签（⌘⇧R）、密码保护、排列、展开、克隆、导出、在父文件夹显示子文件夹内容（勾选）、文件夹图标（emoji）、**颜色色板**、删除。
- 颜色共 8 种：red、orange、yellow、green、aqua、blue、purple、pink，加“无”。多选文件夹可批量设色。
- 检查器选中文件夹：名称（可编辑）、描述（可编辑，支持链接）、文件数、占用空间、添加日期、密码保护、导出。

### API

`/api/v2/folder/update` 支持 `name`、`description`、`tags`、`iconColor`（上面 8 色或空串）、`parent`。没有 emoji 图标、密码、导出、删除。**注意**：审查文档已记录 `update` 不带 `parent` 会移到根、不带 `iconColor` 会清色，实施前要先实测当前 Eagle 4.0.0 是否仍如此，写入时始终带上原值。

### 建议

- **推荐（全做）**：文件夹右键（侧栏、卡片、多选）加色板；检查器选中文件夹时名称、描述可编辑，显示文件数、占用空间（异步求和、可取消）、添加日期；跨窗口刷新、冲突检查沿用现有机制。
- **不做**：emoji 图标、密码保护、导出（API 不支持，界面上不放）。

## E. 显示子文件夹内容、卡片信息开关

### 原版

- “显示子文件夹内容”：**全局**一个开关（存偏好设置），入口在布局面板、文件夹右键“在父文件夹显示子文件夹内容”、显示菜单（⌘⌥7）。打开后浏览文件夹时连同所有后代文件夹的素材一起列出。
- 卡片信息（布局面板，全局，存 localStorage）：显示名称；显示简介（下拉：尺寸/文件大小/标签/评分/修改日期/创建日期）；显示扩展名；显示扩展名标签；显示标注数。另有缩略图“性能/质量”（质量模式在缩略图很大时改用原图）。

### 建议

- **推荐**：
  1. 全局“显示子文件夹内容”开关，三个入口（布局弹层、文件夹右键、菜单），开时查询带上后代文件夹 ID（现有管线支持），所有分栏与窗口同步；
  2. 布局弹层加原版五个显示开关和“简介”下拉，全局存储、跨窗口同步，CSS class 控制，不影响网格计算。
- **可选**：缩略图“质量”模式（大尺寸改用原图 URL，注意内存）。

## F. 标签管理

### 原版

- 左栏：全部（计数）、未分类（未进群组的标签）、常用标签（可拖入）、“标签群组”列表（可拖动排序、双击重命名、右键菜单、可拖标签进去）。
- 右侧：按分组标题（群组名或首字母）分段，每段多个 chip 横排（带颜色点、名称、使用数）；单击选中（支持多选），双击打开该标签的素材，右键菜单：加入群组/移到群组/从群组移除、搜索包含此标签的项目、加入/移出常用、重命名、合并。
- 群组视图顶部可编辑描述；右键空白可选“分组依据：字母/标签群组”“排列：名称/数量”；顶部有搜索框（模糊匹配高亮）。

### API

有 `tag/get`、`tag/update`（重命名）、`tag/merge`、`tagGroup/*` 全套、`tag/getStarredTags`（**只读**，没有设为常用的接口）。标签颜色不在 API 里（MultiView 现在存本地）。

### 建议

- **推荐**：按原版结构重做：左栏 全部/未分类/常用标签/群组；右侧首字母（中文按拼音）或群组分段的 chip 流式布局 + 计数；顶部搜索；排序 名称/数量；右键菜单对齐原版；拖标签进群组。常用标签只读显示原版的收藏（MultiView 不能修改，菜单里不放“加入常用”，或说明在 Eagle 中设置）。
- **可选**：多选标签批量操作、群组描述编辑（`tagGroup/update` 是否支持 description 需实测）。
