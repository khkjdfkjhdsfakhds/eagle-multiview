# Eagle MultiView 1.6.0

Eagle MultiView 是一个通过 Eagle 本地 HTTP API 工作的非官方多窗口客户端。它可以让同一个 Eagle 资料库同时在多个独立窗口、分栏和局域网移动端中浏览、搜索、筛选、预览、整理、导入与编辑，并把修改同步到所有 MultiView 窗口。

## 本次更新

### 移动端与 Web 访问
- **内置 Web 服务与 PWA 支持**：局域网内可通过手机、平板或电脑浏览器直接访问资料库，支持二维码扫码连接、免密或独立访问密钥。
- **移动端触控优化**：全面支持下拉刷新、双指缩放缩略图、左右滑动手势切图、长按菜单与底部紧凑选择栏。
- **浏览器端传输**：支持在浏览器中直接下载素材及批量上传新文件至 Eagle 资料库。

### 视图与分栏同步
- **新增瀑布流与列表视图**：支持自适应网格、瀑布流 (Waterfall) 与详细列表 (List) 视图切换，每个分栏独立记忆视图偏好；列表视图展示标签、评分、添加日期等详细信息。
- **多分栏联动同步 (Sync Panes)**：新增分栏同步模式，支持多分栏同步滚动、翻页、预览与打分。
- **分栏布局升级**：采用矢量分栏图标，支持双击分割线重置比例与响应式标题。
- **路径栏导航**：顶部新增层级面包屑路径栏，支持直接点击跳转。

### 搜索、筛选与排序
- **主色调色彩筛选**：新增客户端色板匹配筛选，在检查器色板中 Option-点击可直接筛选该色彩素材。
- **高级筛选条件**：新增文件大小、分辨率尺寸、添加日期范围等多维度筛选与单字段精准搜索。
- **排序与记忆增强**：新增随机打乱排序，支持按添加日期、评分、格式类型等排序，各分栏独立记忆排序偏好。

### 整理与交互体验
- **框选橡皮筋工具**：支持在空白区域拖拽框选素材，支持修饰键增选及边缘自动滚动。
- **快捷移动归类**：按住 `Option` 拖拽素材到侧栏或文件夹卡片直接移出原文件夹并归类至目标文件夹。
- **检查器自动保存**：属性修改自动静默保存（失焦或停顿即时写入），新增 Eagle 风格标签建议浮窗与颜色标记。
- **快捷键增强**：数字键 `0-5` 快速评级并在网格展示星级标记，`F2` 快捷重命名，`Space` 音视频播放控制。

### 预览与媒体格式
- **幻灯片放映模式**：支持自定义轮播间隔时间与自动循环播放。
- **预览查看选项**：支持透明通道底色切换（棋盘格/黑/白/无）与一键灰度查看模式。
- **高清预览格式扩展**：支持相机 RAW 格式（CR2/CR3/NEF/ARW/DNG/ORF/RAF/RW2 等）及 PSD/TIFF/HEIC 高清预览，修复 Chromium PDF 预览插件。
- **网格对齐导航**：预览界面键盘方向键导航与素材源网格几何位置严格对齐。

### 性能与系统稳定性
- **侧栏资料库切换**：侧栏直接切换 Eagle 当前打开的资料库。
- **虚拟化网格渲染**：引入 `content-visibility` 虚拟化渲染，大幅降低海量素材下的内存与渲染开销。
- **状态记忆与错误日志**：支持滚动位置记忆与后退恢复；新增错误日志落盘机制（`userData/logs/error.log`）。

## 使用前提与数据边界

- 需要 Eagle 4.0 Build 21 或更新版本，并先在 Eagle 中打开目标资料库。
- MultiView 通过 Eagle 本机 HTTP API 读取和修改资料；不会上传资料库内容到公网。
- 素材属性、归类、导入和回收站操作通过 Eagle API 完成，不直接重写 Eagle 的资料库元数据。
- MultiView 不提供永久删除；移入回收站的素材仍可在 Eagle 中恢复。
