# Eagle MultiView 1.8.4

这一版对照 Eagle 4.0 原版做了一次整体审查，补齐菜单、撤销、文件夹、检查器、标签管理和筛选，并修复审查中发现的可靠性与安全问题。

## 菜单、快捷键与撤销

- 菜单栏按 Eagle 4.0 的结构和文案重排（应用、资源库、文件、编辑、查找、整理、显示、窗口、帮助）。MultiView 原有快捷键不变，补上原版有、MultiView 未占用的 ⌘ 快捷键，例如 ⌘N 新建、⌘E 导出、⌘L 切换资源库、⌘T 添加标签、⌘⌥F 在“全部”搜索、⌘⇧F 筛选器、⌘⌥R 刷新缩略图、⌘⌥4～7 卡片显示开关。
- “Web 访问…”移到应用菜单（Eagle MultiView 菜单）。
- 撤销与原版一致：最近一次可撤销操作的提示条带“撤销”，点链接或按 ⌘Z 撤销，提示消失后约 5 秒内有效。覆盖删除素材、移出/添加/移动到文件夹、重命名文件夹和智能文件夹、批量重命名、删除文件夹/智能文件夹/标注、清除标签。输入框内 ⌘Z 仍是文字撤销。
- 在输入框里打字时菜单快捷键不触发；弹窗打开时菜单命令等待。⌘A 全选整个视图（不限于已加载的 3,000 项），Shift 点选与 Shift 方向键从上次点击处扩展。

## 文件夹

- 从侧栏或文件夹卡片删除文件夹（菜单或 ⌘⌫），走 Eagle 自己的删除流程，带“同时删除内容”选项。
- 侧栏可 ⌘ / ⇧ 多选文件夹：合并显示内容，批量移动、设颜色、重命名、删除。
- 按目录结构导入本地文件夹：拖到侧栏空白处，或用“文件 › 导入本地文件夹…”。拖到已有文件夹上只导入文件，与原版一致。
- 文件夹的“Eagle 顺序”跟随它在 Eagle 里设置的排序；拖动排序只写入被移动的素材。
- 归类或导入到文件夹时加上该文件夹的自动标签；文件夹颜色、描述、“显示子文件夹内容”等与原版对齐。

## 检查器、标签与筛选

- 检查器按原版补全：所属文件夹、五星评分、字段顺序与日期、多选时批量备注/链接与共同文件夹、区块折叠与排序、导出按钮；当前素材离开视图后选中下一张。
- 标签管理按原版重做：群组颜色与描述、首字母分段、右键菜单、拖入群组、批量重命名（⌘R）、列表布局。群组顺序只保存在 MultiView 本地（Eagle API 不支持群组排序）。
- 新增“整理 › 清除标签”和素材批量重命名。
- 筛选面板补齐原版条件：文件夹、修改日期、时长、标注、链接、形状、评分、大小，任一/全部/相同与排除，日期预设。切换视图会清空搜索与筛选，除非“锁定筛选”。

## 预览、布局与导入

- 触屏预览点左右三分之一翻页，或拖动像相册一样滑入下一张；预览中 ⌘C 复制当前素材。
- 瀑布流按行填入最短列；列表布局有可排序、可选列的列头。
- 从浏览器拖入的图片和链接可导入，包括内嵌的 `data:` 图片；小窗口和窄分栏里菜单、弹层、标签管理和对话框都可用。

## 网页端与 Android App

- 网页端：拒绝 DNS 重绑定和跨站写入；主机重启或页面从缓存恢复后自动重新同步；长时间上传显示进度并保持连接；下载可续传；PDF 用 Eagle 自己的查看器打开；“Web 访问”窗口说明明文 HTTP 的风险。
- Android App：有未保存编辑时按返回会先询问；连接页和失败页按返回直接退出；等待安装权限的更新在重启后保留；系统回收渲染进程后自动重新加载；主题、字体和显示设置变化不再重新加载页面；移动网络下局域网地址连不上时给出提示。

## 可靠性与安全

- 渲染进程无响应或有待保存内容时也能正常关窗和退出；有未保存编辑时重新载入窗口会先询问。
- 收紧 Electron 安全设置：关闭 `ELECTRON_RUN_AS_NODE`、`NODE_OPTIONS` 和 `--inspect`，启用 asar 完整性校验；只允许全屏和写剪贴板的页面权限请求。
- 生成信息在后台线程读取并有大小和时间限制；重复索引和缩略图只刷新变化的部分；大回收站扫描可以完成。

完整列表见 [CHANGELOG](https://github.com/khkjdfkjhdsfakhds/eagle-multiview/blob/v1.8.4/CHANGELOG.md)。

## 下载与升级

- macOS Apple silicon：`Eagle-MultiView-1.8.4-arm64.dmg`。临时本机签名，未经 Apple 公证；首次打开请在 Finder 中右键选择“打开”。1.8.2 及以后的版本可在 App 内更新。
- Android：`Eagle-MultiView-1.8.4-android.apk`。改为不可调试的 release 构建，签名证书与之前版本相同，可直接覆盖安装并保留数据；1.8.2 及以后的 App 可在 App 内更新。
- 校验文件：`SHA256SUMS.txt`。
- 编辑 TXT 仍需在 Eagle 中启用 App 随附的后台保存插件，见[启用说明](https://github.com/khkjdfkjhdsfakhds/eagle-multiview/blob/v1.8.4/eagle-plugin/text-save-service/README.md)。
- 内置 Web 服务为 HTTP，仅用于可信局域网，不要直接映射到公网。
- 不提供 Windows 桌面版。
