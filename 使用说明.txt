Eagle MultiView 使用说明

使用方法
1. 先启动 Eagle 4.0，并打开要浏览的资料库。
2. 从“应用程序”启动 Eagle MultiView。
3. 从“文件”菜单或按 Command-Option-N 新建独立窗口。
4. 每个窗口还可以选择单栏、双栏、三栏或四栏布局；每个视图可以分别停留在不同文件夹、搜索或筛选结果。

当前版本：1.8.0。桌面版仅提供 macOS Apple silicon，停止 Windows 桌面构建和维护。
完整功能与公开演示截图见 README.md，累计更新见 docs/release-notes-v1.8.0.md。

网页与手机连接
1. Mac 上保持 Eagle 与 MultiView 运行。
2. 在 MultiView 菜单“显示 → Web 访问…”中启用并应用，默认端口 41600。
3. 手机、平板或另一台电脑连接同一局域网，扫描地址二维码或输入显示的地址，再输入访问密钥。
4. 可浏览、搜索、预览、整理、上传和下载；Finder 等系统操作仅在 Mac 桌面版可用。
5. 内置服务使用 HTTP，仅用于可信网络，不要直接映射到公网。主机睡眠或退出后远端连接中断。

当前功能概览
- 新增内置局域网 Web 访问与 PWA 支持：手机/平板/电脑浏览器扫码访问，支持触控手势、免密登录与文件上传下载。
- 新增自适应网格、瀑布流 (Waterfall) 与详细列表 (List) 视图，分栏独立记忆视图模式。
- 多分栏同步仅联动全屏预览；网格滚动、选择与整理操作保持各栏独立。手机窄屏下多栏纵向排列，可上下滚动访问；转回宽屏会恢复布局与比例。
- 新增主色调色彩筛选（检查器色板一键筛选）、文件大小/分辨率/添加日期高级筛选与字段搜索。
- 新增框选橡皮筋工具、Option 拖拽移出归类、检查器自动静默保存、标签建议浮窗与 0-5 快捷打分。
- 新增幻灯片放映模式、预览透明通道底色切换（黑/白/棋盘格）、一键灰度模式。
- 新增相机 RAW 格式（CR2/CR3/NEF/ARW/DNG 等）与 PSD/TIFF/HEIC 高清预览支持。
- 新增侧栏资料库快速切换器、大图库虚拟化滚动优化与错误日志落盘。

目录浏览
- 左侧文件夹按真实父子层级嵌套显示；每个新窗口默认全部收起。
- “资料库根目录”显示一级文件夹和未分类的根目录文件；“全部素材”显示全库素材。
- 打开文件夹后只显示直属子文件夹和直属文件，不递归混入后代图片。
- 双击文件夹卡片，或单击选中后按 Return 进入。
- 可使用返回、前进、上一级、路径导航，以及 Option-左/右/上方向键。
- / 与 Eagle 原版一致：根据当前层级在“全部展开”和“全部收起”间切换；展开时会定位并高亮当前文件夹。
- 方向键在卡片间移动；Space/Return 预览素材，Command-O 在新窗口打开所选素材或文件夹，Shift-Return 用默认应用打开。
- TXT 可直接预览和编辑，停顿后自动保存，Command-S 可手动重试；需要配套 Eagle TXT 后台插件。图片、视频、音频、PDF 等可直接预览，PSD 等使用 Eagle 缩略图。
- 右键素材可打开原文件、在 Finder 中显示、复制路径/名称或移入废纸篓。
- Space 打开和关闭预览；预览中用左右方向键切换后，关闭时会选中最后看到的素材。
- Command-Shift-L / Command-Shift-I 可收起文件夹栏 / 检查器。

导入与整理
- Option-N 新建文件夹；Option-Shift-N 新建 TXT；也可以从“新建”菜单创建其它支持的文档和智能文件夹。
- 点击工具栏“导入”、按 Command-Shift-O，或把文件拖到中央素材区即可导入。
- 在 Finder 复制一个或多个文件后，回到素材区按 Command-V 可直接导入；剪贴板中的图片也可导入。
- 在普通文件夹中导入时进入当前文件夹；在根目录、全部素材、智能文件夹等视图中导入为未分类素材。
- 素材可在当前普通文件夹内置顶；置顶顺序保存在 MultiView 自己的状态中，并实时同步到所有 MultiView 窗口，不改写 Eagle 资料库元数据。
- 标签使用可添加、粘贴和逐个移除的标签块；支持逗号、中文逗号或 Return 快速添加。
- Web 下载每次最多 500 项、合计 3.5GB，开始前核验全部选择；超量或原文件缺失会明确提示，不静默省略。“已开始下载”不代表浏览器已下载完成，传输状态请查看浏览器下载列表。
- Web 普通 HTTP 或剪贴板权限受限时，会弹出可选原文供系统手动复制；实际复制后再点击“已手动复制”。

数据安全
- MultiView 不会直接修改 Eagle 的 metadata.json。
- 素材属性、归类和导入都交给当前运行的 Eagle Web API 保存。
- TXT 保存先检查内容版本，在 MultiView 自身数据目录保留草稿及最近20个不同正文的备份，再由 Eagle 官方后台插件提交；没有 MultiView 直接覆盖资料库的回退。自动保存不主动打开或激活 Eagle 窗口。
- 插件缺失、保存失败或冲突时保留草稿；重新打开素材可选择恢复其它会话的草稿，不会自动覆盖。零字节正文暂不提交，不补空格假装保存成功。
- 同一素材的写入会排队；保存前会检查另一个窗口是否改了同一字段。
- 未保存修改在切换素材、切换文件夹或关闭窗口前会被拦截确认。
- 红色关闭按钮、Command-W 和 Command-Q 都会显示明确的未保存确认。
- 标签和文件夹增删会在最新值上合并，避免旧数组覆盖新值。
- 一个 MultiView 窗口保存后，其他窗口会立即收到更新。
- Eagle 原生窗口中的修改会自动检测并刷新，通常约 1 秒触发。
- Eagle 断开时编辑控件会禁用，不会离线积压后擅自回写。
- 删除仅移入 Eagle 废纸篓，不提供永久删除。

当前支持
- 文件夹、智能文件夹、最近使用、随机模式、回收站、快速访问和未分类浏览
- 多窗口与单窗多分栏独立浏览
- 名称/标签/格式/评分筛选与搜索
- 图片、GIF、SVG、视频、音频、PDF、TXT 预览；TXT 可编辑
- 修改名称、标签、评分、备注、来源网址
- 拖到文件夹归类、批量添加标签、文件选择/拖拽/复制粘贴导入、导出、创建副本、当前文件夹置顶、移入废纸篓
- 读取 NovelAI、Stable Diffusion WebUI、ComfyUI、InvokeAI 等常见图片生成信息

1.5.2 功能更新
- 新增单栏、双栏、三栏和四栏布局，每个分栏保持独立的导航、筛选、选择、滚动和预览状态。
- 新增文件夹、TXT/其它文档、智能文件夹创建，以及导出、创建副本和常见生成信息读取。
- 完善跨窗口/跨分栏拖放、批量操作、异步保存、部分失败反馈和关闭保护。
- 新建文件夹改为 Option-N，新建 TXT 改为 Option-Shift-N，新窗口改为 Command-Option-N。
- 修复文件夹封面比例、拖入文件夹卡死、慢请求覆盖其它分栏等问题。

1.5.1 功能更新
- 右键菜单改为 Eagle 风格浮层，补齐文件夹、标签、评分、置顶、回收站和恢复操作。
- 工具栏筛选改为弹出面板，统一管理关键词、格式、评分和标签。
- 检查器按预览、基本信息、备注与来源、文件信息分区，并显示格式标志。
- 图片缩略图不再显示 PNG/JPG 等格式角标；PSD、TXT、PDF 和音视频继续显示。
- 图片预览支持适应窗口、实际大小、缩放、拖动和当前序号。
- 修复高纵向图片在适应窗口模式下被放大裁切的问题。
- 标签颜色保存在 MultiView 自己的应用数据目录，不写入 Eagle 资料库。

1.5.1 界面更新：背景、侧栏和内容区配色对齐 Eagle 原版的中性深灰风格，并复用 Eagle 原始界面图标。

1.5.0 界面更新
- 使用原创鹰系萌娘与双窗口形象替换旧的 M 图标；Finder、Dock 和标题栏统一为新图标。
- 标题栏为 macOS 窗口按钮预留更宽的安全间距。
- 重做标题栏、工具栏、侧栏、素材网格、检查器、状态栏和预览界面的视觉层级。
- 左侧文件夹与特殊入口改为统一的矢量图标，选中、悬停和定位状态更清晰。

注意
- 需要 Eagle 4.0 Build 21 或更新版本。
- Eagle 切换资料库时，所有 MultiView 窗口会统一跟随。
- 切换资料库会清空旧库缓存，排队写入也会再次核对资料库，避免跨库误写。
- 插件、资料库合并/修复、永久删除等管理功能继续在 Eagle 中使用。
- 此版本为本机临时签名版本；若 macOS 首次拦截，请在 Finder 中右键应用并选择“打开”。
- GitHub 同时提供未签名的 Windows x64 实验性安装包；该版本未完成 Windows 实机 GUI 回归，后续不承诺兼容性修复、更新或维护。
